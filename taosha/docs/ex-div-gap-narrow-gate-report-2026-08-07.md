## 三、官方字段、单位与 Decimal 口径

Tushare官方 `dividend` 字段定义：

- `stk_div`：每股送转；
- `stk_bo_rate`：每股送股比例；
- `stk_co_rate`：每股转增比例；
- `div_proc`：实施进度；
- `ex_date`：除权除息日；
- `imp_ann_date`：实施公告日。

来源：[Tushare 分红送股接口文档](https://tushare.pro/document/2?doc_id=103)。

故登记条件“送转合计>=0.5”的最小忠实口径为：

```text
total = Decimal(str(stk_div))
component_sum = Decimal(str(stk_bo_rate or 0))
              + Decimal(str(stk_co_rate or 0))
event iff total >= Decimal("0.5")
```

含义是每股合计送转0.5股，即通常表述的“每10股送转合计5股”。恰等0.5必须入选；不能将0.5按浮点近似比较，也不能把现金分红字段加进送转比例。

批17只读核验：

- 在SH/SZ、`ann_date<2024-07-01`范围内，126,900行按阶段恰分为：预案52,084、股东大会通过27,822、实施46,879、未通过95、停止实施17、其他3；
- 实施行中46,831行具有 `ex_date`，且46,831行均有 `stk_div`；
- 46,830/46,831行满足 `stk_div = coalesce(stk_bo_rate,0)+coalesce(stk_co_rate,0)`；唯一不一致是 `600211.SH/2010-06-30`，处于2011研究期之前；
- 研究期内4,075个高送转实施行的分项均能精确重建合计：`送股为空3,688 / 两项均在278 / 转增为空109`，无“两项皆空却依赖合计”的高送转事件；
- 全历史实施且有除权日的行中，`stk_div>=0.5` 为5,993行，恰等0.5为1,748行；
- `cash_div_tax>=0.5`但送转合计不足0.5的行有3,640行，直接证明现金分红不能代理高送转。

分项空值只能在合计与另一分项精确对账时视为0；任何合计/分项冲突必须整组 fail-closed。

## 五、前复权、后复权与不复权的命题含义

Tushare官方复权公式为：

- 前复权：`qfq_close = raw_close * adj_factor / latest_adj_factor`；
- 后复权：`hfq_close = raw_close * adj_factor`；
- 不复权：原始名义价格。

来源：[Tushare 复权行情说明](https://tushare.pro/document/2?doc_id=146)。

对同一证券与固定样本窗，前复权与后复权只相差一个证券内常数，因此任意两日的对数收益完全相同：

```text
log(qfq_t / qfq_s) = log(hfq_t / hfq_s)
```

现有 qbase 价格视图使用 `raw close * adj_factor`，即后复权口径；引擎再从该价格计算对数收益。因此现有主判决路径已经是总回报意义下的复权收益，前复权或后复权标签不会改变同窗收益。

不复权收益则满足：

```text
raw_log_return = adjusted_log_return - log(adj_factor_t / adj_factor_s)
```

除权日的机械价格重置会直接进入不复权收益。以纯送转0.5为例，理论名义价格从 `P` 变为 `P/1.5`，简单收益约为−33.3%，对数收益约为−40.55%；这不是投资者财富损失，而是股份数增加后的计价恒等式。若把不复权收益送入CAR，几乎必然制造巨额负跳空，测到的是公司行动会计机械量，而不是“低名义价格带来后续追捧”。

因此建议：

- 主事件CAR必须用现有复权总回报价格；
- “名义价格幻觉”应解释为：机械除权影响被复权消除后，除权当日及后续是否仍出现正的市场调整异常收益；
- 不复权跳空仅作 `NOT_FOR_VERDICT` 的机械完整性诊断，不得进入顶层 verdict、不得作为事件方向或显著性证据；
- `tau0` 应取除权日当日：批17研究期高送转实施行全部满足 `imp_ann_date < ex_date`，信息在除权日前已公开，机械重置与可能的行为反应均从当日开始；既有 `tau0_on_anchor=True + missing_bar_only` 可复用，缺bar最多顺延5个交易日，一字板有真实bar仍只作价格观察。

若人坚持把不复权跳空本身作为估计量，那已不是现有异常收益命题，而是公司行动机械价格研究，应停止exp14并重新登记，不能在PAP中静默改写。

## 六、监管收紧阶段

监管阶段事实可证：

- 证监会在2017年将高送转列为专项检查与高压执法对象；来源：[证监会2017年专项执法说明](https://www.csrc.gov.cn/csrc/c100029/c1000122/content.shtml)；
- 上交所与深交所在2018-11-23发布高送转信息披露规则；来源：[上交所规则说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20181123_4681607.shtml)、[深交所通知](https://www.szse.cn/disclosure/notice/t20181123_557697.html)；
- 深交所2018年规则对不同板块采用不同“高送转”阈值：主板每10股5股、中小板8股、创业板10股；来源：[深交所2018年规则PDF](https://docs.static.szse.cn/www/disclosure/notice/W020181123645100187545.pdf)；
- 2021年板块合并后阈值结构再次调整，后续规则又有替代；来源：[深交所2021年修订稿](https://www.szse.cn/lawrules/rule/repeal/rules/P020231230545141390866.pdf)、[后续废止/替代记录](https://www.szse.cn/lawrules/rule/repeal/rules/P020250331546072254413.pdf)。

因此登记的统一 `stk_div>=0.5` 是研究事件定义，不等同于所有市场、板块与年份的监管“高送转”法律标签。不能按监管阈值静默改变样本；监管制度只能作为另一个时点/板块维度如实披露。

只按两个制度时点做事件数量NFV，因子门候选分布为：

| 阶段 | 日期口径 | 候选 | 恰等0.5 |
|---|---|---:|---:|
| 收紧前 | `<2017-01-01` | 2,688 | 613 |
| 执法过渡 | `2017-01-01..2018-11-22` | 664 | 170 |
| 交易所规则后 | `>=2018-11-23` | 686 | 300 |

该三分只能作为粗粒度事件数量/组成诊断；它没有板块历史映射，不能冒充精确监管制度分层。

现有内核只有 `listing_age/st/direction` 等通用诊断轴，另有若干实验专属分层；不存在可直接复用的通用监管阶段收益轴。PAP草案须呈拍：

1. **R1（最小建议）**：监管阶段只报告事件数量、比例与板块可用性，全部NFV，不计算分阶段CAR或显著性；零新统计能力；
2. **R2**：监管阶段必须做CAR/ADJ-BMP诊断。此项需要先闭合板块历史映射，并获准增加最小通用诊断轴；治理冻结期若不允许新增能力，则exp14不得冻结。

不得借用 forecast 专属 `type_strata` 或拆出多个顶层 verdict；也不得按分阶段显著性回改统一0.5阈值。
