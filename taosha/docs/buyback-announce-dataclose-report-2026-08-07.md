## 4. 官方原件硬门

核验仅使用巨潮官方元数据与发行人 PDF 正文。标题只定位原件；通过必须同时满足：

1. 公告日找到发行人原件；
2. 正文证明当次董事会初始回购方案，不是修订/调整件；
3. 正文回购价格与源表 `high_limit` 使用 Decimal 零容差精确相等，以证明方案身份；
4. 用途只由正文明确句判为注销式、库存式或其他明确用途；无正文证据即不可分类。

抽样方式固定为2011–2024每年2例，在预置研究期内的 C1 单行预案键10,986中按时序等距取28例。
四轮证据完整保留，识别窄修只改原件定位、精确文本形式和修订文书误报，未改日期、价格零容差或用途证据标准：

| 轮次 | 通过/抽核 | 处置 |
|---|---:|---|
| 初版 | 1/28 | 原件标题定位假阴性暴露，原件保留 |
| v2 | 3/28 | 放宽“定位原件”的文书类，不改正文通过标准 |
| v3 | 14/28 | 补入限制性股票注销与“不高于”的正文精确规则 |
