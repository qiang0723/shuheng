## 2. 无前视与机械读法

本轮只读取`ts_code/trade_date/open/close/amount`；`open/close`仅用于事件日本身“收阳”谓词，未读取任何事件日后收益、CAR或显著性。

机械读法（仅供核验）：

1. 当日60日均值只取此前60根正成交额真实bar，排除当日；
2. `amount < 0.30 × prior60_mean`连续至少5个交易bar后进入armed状态；
3. 交易所日历出现缺bar时打断低量段与armed状态；NULL/非正成交额或缺开收盘同样打断；
4. armed后首个同时满足`amount > prior60_mean`且`close > open`的bar为事件；均值逐日滚动；
5. 每个armed阶段最多一个事件，事件后必须重新形成五日低量段；
6. 研究期机械取`2011-01-01 ≤ event_date < 2024-07-01`。

## 4. 材料性歧义与待人菜单

唯一需要在PAP前重点拍清的是“首个放量且收阳”的阶段终止语义。本轮“等待首次联合满足”读法下：

- armed至事件等待中位数20个bar，P90=42，最大120；
- 等待≤5个bar仅`1,713/17,220=9.95%`；等待>20个bar为`8,417/17,220=48.88%`；>60个bar为`308/17,220=1.79%`；
- 全史armed期间曾出现`10,562`次“成交额已放量但当日不收阳”。

因此PAP须在人裁以下二者择一，不能由施工方代选：

- A：等待首个同时放量且收阳的bar，允许中间中性或放量阴线；
- B：低量段后的第一次放量bar即阶段终局；若该bar不收阳则整段不成事件，随后重新武装。

B更贴近“干涸后的首次放量突破”语义并自然避免超长等待，但会改变样本，故本轮不代裁、不重算择优。

其余待裁项：60日均值排除当日；停牌缺bar是打断还是暂停；均值滚动还是在低量段末锚定；“收阳”固定为`close>open`；零/NULL成交额fail-closed；不足60bar排除；研究期起点；一阶段一事件及重新武装规则。机械边界恰等30%与恰等100%本轮均0例，但闭区间符号仍须写死。
